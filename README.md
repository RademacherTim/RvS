# RvS
Code for research project on a comparison of red and sugar maple sap and syrup production.

This study was initialized by Abby van den Berg in 2022 and has continued with the help of Wade Bosley, Mark Isselhardt and Tim Rademacher until 2027. The study installed two separate systems of tubing in a mixed stand containing red and sugar maple trees: one for red maple and one for sugar maple trees. Each system goes to a separate releaser, which is monitored daily to with the help of a water flow meter to quantify the sap volume. Moreover, somebody (mostly Wade Bosley) has measured sap soluble concentration with a MISCO refractometer each day of a sap run and noted the vacuum level on the system.
